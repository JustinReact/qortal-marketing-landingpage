# Setting Up a New Q-App ⚙️

## What You’ll Need

- Latest version of Node.js
- An IDE such as VS Code
- Qortal Hub

---

## Setting up a New Q-App Quickly

Use the npm package `create-qortal-app` to quickly set up a new Q-App.

### Step 1: Install globally

```bash
npm install -g create-qortal-app
```

### Step 2: Run create-qortal-app

```bash
npx create-qortal-app
```

### Step 3: Enter the name of your app

```bash
? Enter the name of your app: my app
```

### Step 4: Choose a template

```bash
🔍 Fetching available templates...

? Select a template: (Use arrow keys)
❯ react-default-template
```

Wait about a minute while the project is created.

If you're using VS Code, the project may open automatically.
If not, open your IDE and navigate to your project folder manually.

### Run the App in Development Mode

```bash
npm run dev
```

By default, Vite will serve your app with port: 5173
